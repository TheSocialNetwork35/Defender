# Publication gate

- [ ] Review all new source and security/concurrency behavior manually.
- [ ] Complete MANUAL_TESTS.md with exact server/client/PacketEvents/Java/proxy build IDs and actual results.
- [ ] Validate Paper 26.3 gameplay, movement, interactions, combat, inventories, vehicles and elytra.
- [ ] Test Bukkit/Folia individually; keep Fabric unlisted until a real build and runtime test exist.
- [ ] Establish measured false-positive baselines with clean clients, high latency and low TPS.
- [ ] Complete third-party license/source audit, including all shaded libraries and exact snapshot sources.
- [ ] Publish exact corresponding source/build scripts and source dependencies alongside binary access, as required by GPL.
- [ ] Verify distributed JAR/source/checksum correspondence and all notices in THIRD_PARTY.md.
- [ ] Resolve current Modrinth primarily-AI-generated and substantial-divergence eligibility. Do not assume disclosure grants permission.
- [ ] Re-read current Modrinth rules at upload time; set derivative and AI code/text disclosures honestly.
- [ ] Keep all untested compatibility/detection claims out of public metadata.
- [ ] Use real human-created assets only, or no artwork.
- [ ] Review privacy notice and operator-enabled webhook/history settings.
- [ ] Confirm no accidental credentials, world/player data, or build logs containing private data are published.

This checklist is intentionally not pre-ticked: build/test results are evidence in TEST_RESULTS.md, not a substitute for publication review.
